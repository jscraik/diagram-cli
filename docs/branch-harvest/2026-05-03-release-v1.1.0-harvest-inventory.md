## Unsafe Import Notes

Direct merge or default cherry-pick is blocked.

The aggregate diff would delete current `src/artifacts/**`, `src/commands/**`,
`src/context/**`, `src/schema/**`, `src/renderers/report-html.js`, multiple
current specs/plans, validation scripts, and a large set of tests. The useful
release-branch ideas must therefore be translated into current-main
requirements and rebuilt through current owner modules.

The release branch also concentrates large behavior in `src/diagram.js` and
`src/core/analysis-generation.js`. Current `main` has split those surfaces into
smaller command, artifact, context, schema, renderer, workflow, and analysis
modules. Reintroducing the stale shape would regress maintainability and the
Archscope evidence-first product model.

## Next Theme Selection

Selected theme: AI-native type metadata.

Why selected first:

- It best supports the product north star: architecture evidence for humans and
  AI coding agents.
- It can be evaluated against stable current artifacts before changing runtime
  behavior.
- It is less likely than diagram, cache, or confidence work to pull the code
  back toward stale branch implementation shape.

Deferred themes:

- Diagram quality: defer until a concrete current fixture or snapshot gap is
  recorded.
- Cache trust: defer until current scan/PR cache usage is documented.
- Confidence actionability: defer until current confidence signals are
  inventoried and tied to concrete recovery behavior.

Discarded or document-only candidates:

- Workflow and deep-regression changes are not imported from the branch. They
  remain context for later validation or CI-specific work only.
- The code-scanning cleanup commit is context for checking current code, not a
  source patch.
